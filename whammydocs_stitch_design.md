# Project Brief: WhammyDocs

## Overview
WhammyDocs is an AI-powered documentation generator that transforms project source code (ZIP uploads) into structured, high-fidelity documentation websites in seconds. The platform provides a seamless, immersive experience from upload to final review.

## User Journey
1. **Upload**: Users drop a `.zip` file and select a generation mode (Quick or Comprehensive).
2. **Generation**: A real-time progress screen shows AI modules being built, accompanied by a progress-synced background animation.
3. **Review**: A final preview interface allows users to inspect, edit, or regenerate specific modules before downloading the final ZIP.

## Visual Identity (Lumina Docs)
The design uses a high-contrast, modern aesthetic with a focus on immersive gradients and clean typography.

### Color Palette (New Palette)
- **Primary Action**: Periwinkle (#E4D9FF) - Used for primary buttons and active states.
- **Accent/Success**: Tea Green (#C8FFBE) - Used for progress indicators, secondary accents, and positive feedback.
- **Base Surface**: Jet Black (#292F36) - Provides a deep, professional foundation for dark mode interfaces.
- **Secondary Surface**: Thistle (#D0C4DF) - Used for subtle highlights and component surfaces.

### Typography & Style
- **Font**: Unnageo Extra Bold for headers, Unnageo medium for sub headers, unnageo regular for generated text
- **Roundness**: 8px (Round Eight)
- **Atmosphere**: Immersive, high-fidelity, and "AI-native."

## Key Design Features
- **Dynamic Gradient Progress**: The background features a Tea Green to Periwinkle gradient that "fills" from the bottom up in sync with the generation progress bar.
- **Dark Mode Preview**: A premium dark-themed review interface with a full-page gradient glow to denote completed status.
- **Collapsible Documentation Modules**: Structured layout for README, API Reference, Architecture, etc., with manual "Edit" and "Regenerate with AI" controls.

## Technical Specifications
- **Device Support**: Optimized for Desktop.
- **Components**: Shared navigation header and sticky right-hand table of contents.
- **Interactions**: Smooth transitions between upload, generating, and preview states.
