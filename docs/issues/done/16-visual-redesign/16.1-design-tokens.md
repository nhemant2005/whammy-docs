## What was built

Created `static/css/theme.css` — the single source of truth for the Lumina Docs palette, loaded by every template via `<link rel="stylesheet" href="/static/css/theme.css">`.

**`@font-face` declarations:**
- Unageo Regular (`Unageo-Regular.ttf`) — weight 400, normal
- Unageo Regular Italic (`Unageo-Regular-Italic.ttf`) — weight 400, italic
- Unageo Medium (`Unageo-Medium.ttf`) — weight 500, normal
- Unageo ExtraBold (`Unageo-ExtraBold.ttf`) — weight 800, normal

**CSS custom properties on `:root`:**
```css
--color-base:       #292F36;
--color-surface:    #363c45;
--color-border:     rgba(208, 196, 223, 0.25);
--color-primary:    #E4D9FF;
--color-accent:     #C8FFBE;
--color-text:       #F0EBF8;
--color-text-muted: #A89BBC;
```

**Body base rule:**
```css
body {
  font-family: 'Unageo', sans-serif;
  background-color: var(--color-base);
  color: var(--color-text);
}
```

**FastAPI `StaticFiles` mount** — was not pre-existing in `main.py`. Added:
```python
from fastapi.staticfiles import StaticFiles
app.mount("/static", StaticFiles(directory="static"), name="static")
```

**Template links** — `<link rel="stylesheet" href="/static/css/theme.css" />` added to `upload.html`, `preview.html`, and `generate.html`.

**New test file:** `tests/test_theme.py` — 2 tests:
- `GET /static/css/theme.css` returns 200 with `text/css` content-type
- `GET /static/unageo/ttf/Unageo-Regular.ttf` returns 200
