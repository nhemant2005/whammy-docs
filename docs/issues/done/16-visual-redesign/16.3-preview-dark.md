**GitHub:** #19
**Label:** done

## What was built

`preview.html` fully rewritten in the Lumina Docs dark theme. All functionality preserved — only visual treatment changed. All colours via CSS custom properties.

**CSS component classes (defined in `<style>` block):**

- `.section-card` — `var(--color-surface)` bg, 1px `var(--color-border)` border, 8px radius, `overflow: hidden`
- `.section-card.active` — `var(--color-primary)` border-color + soft Periwinkle box-shadow (applied by JS on `section-start`)
- `.card-header` — `rgba(255,255,255,0.03)` background, `var(--color-border)` bottom border, cursor pointer
- `.btn-primary-sm` — `var(--color-primary)` bg, `var(--color-base)` text, 8px radius (Download ZIP, Save, Generate inside feedback panel)
- `.btn-ghost-sm` — transparent bg, `var(--color-border)` border, `var(--color-text-muted)` text (Edit button)
- `.btn-regen-sm` — transparent bg, `rgba(228,217,255,0.35)` border, `var(--color-primary)` text (Regenerate with AI idle)
- `.btn-regen-cancel` — transparent bg, `var(--color-border)` border, `var(--color-text-muted)` text (Cancel state)
- `.skeleton-bar` — `rgba(255,255,255,0.08)` background; `.skeleton-bar.active` — `rgba(228,217,255,0.15)` (applied by JS on active section)
- `.feedback-panel` — `var(--color-base)` bg, `var(--color-border)` bottom border
- `.feedback-textarea` — `var(--color-surface)` bg, `var(--color-text)` text, `var(--color-border)` border, Periwinkle focus ring
- `.toc-sidebar` — `var(--color-surface)` bg, `var(--color-border)` border, 8px radius
- `.toc-link` — `var(--color-text-muted)` text; hover: `var(--color-text)` + faint surface bg
- `.editor-textarea` — `var(--color-base)` bg, `var(--color-text)` text, `var(--color-border)` top border, monospace font
- `.unsaved-bar` — `rgba(200,255,190,0.06)` bg, `var(--color-accent)` text
- `.error-banner` — `rgba(220,38,38,0.12)` bg, rose border, `#f87171` icon, `#fca5a5` text
- `.download-disabled` — `rgba(255,255,255,0.06)` bg, `var(--color-text-muted)` text

**Prose dark overrides:**
- All headings and body text: `var(--color-text)`
- `pre` blocks: `var(--color-base)` bg + `var(--color-border)` border
- Inline `code`: `var(--color-base)` bg, `var(--color-accent)` text
- Links: `var(--color-primary)`
- `blockquote`: `var(--color-border)` left border, `var(--color-text-muted)` text

**Header:**
- Frosted dark glass: `rgba(41,47,54,0.92)` + `backdrop-blur-sm`
- "Start over" link: `var(--color-primary)`
- Download ZIP: `var(--color-primary)` bg when active; `.download-disabled` when generating

**Progress bar:**
- `#gen-progress-bar`: `linear-gradient(to right, var(--color-accent), var(--color-primary))` (Tea Green → Periwinkle)
- `#gen-progress-wrap`: `rgba(255,255,255,0.05)` background

**JS updates:**
- `setSectionActive`: applies `.active` class to card + sets badge to Periwinkle tint; adds `.active` to skeleton bars
- `setSectionDone`: removes `.active`; badge uses `rgba(200,255,190,0.12)` bg + `var(--color-accent)` text
- `REGEN_ICON_REFRESH` / `REGEN_ICON_X` string constants replace the old `REGEN_CLASS_*` + `REGEN_BTN_*` constants
- `revealAll`: sets Download ZIP inline styles to Periwinkle, removes `.download-disabled`

**Skeleton animation:** CSS `@keyframes pulse` (opacity 1→0.4→1) defined in a second `<style>` block; applied via `animation` property on skeleton container.
