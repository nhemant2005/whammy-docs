# Issue 16.1 — Shared design token layer (theme.css + Unageo font-face)

**GitHub:** #17
**Label:** ready-for-agent
**Blocked by:** None

## What to build

Create `static/css/theme.css` — a single shared stylesheet loaded by every template that defines:

- `@font-face` declarations for Unageo Regular (400), Medium (500), and ExtraBold (800) pointing to `static/unageo/ttf/`
- CSS custom properties on `:root`:
  - `--color-base: #292F36` (page background)
  - `--color-surface: #363c45` (card/surface background)
  - `--color-border: rgba(208, 196, 223, 0.25)` (Thistle at 25% opacity, for card edges)
  - `--color-primary: #E4D9FF` (Periwinkle — primary buttons, active states)
  - `--color-accent: #C8FFBE` (Tea Green — progress/success indicators)
  - `--color-text: #F0EBF8` (near-white body text)
  - `--color-text-muted: #A89BBC` (muted lavender-gray for secondary labels)
- `body { font-family: 'Unageo', sans-serif; background-color: var(--color-base); color: var(--color-text); }`

Link this stylesheet from all three templates (`upload.html`, `preview.html`, `generate.html`) via `<link rel="stylesheet" href="/static/css/theme.css">`. Tailwind CDN stays for layout utilities — this file only overrides colour and typography.

FastAPI already mounts `StaticFiles(directory="static")` so `theme.css` is available at `/static/css/theme.css` immediately.

Add two tests to a new `tests/test_theme.py`:
- `GET /static/css/theme.css` returns 200
- `GET /static/unageo/ttf/Unageo-Regular.ttf` returns 200
