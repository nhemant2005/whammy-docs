# Issue 16.4 — Gradient layer: Tea Green → Periwinkle fill synced to generation progress

**GitHub:** #20
**Label:** ready-for-agent
**Blocked by:** Issue #19 (16.3)

## What to build

Add a fixed full-viewport gradient layer to `preview.html` that reveals from bottom to top in sync with section generation progress.

**Gradient layer div** — first child of `<body>`, always present:
```html
<div id="gradient-layer"></div>
```
```css
#gradient-layer {
  position: fixed;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  background: linear-gradient(to top, var(--color-accent), var(--color-primary));
  clip-path: inset(calc(100% - var(--gradient-progress, 0%)) 0 0 0);
  transition: clip-path 600ms ease-out;
}
```

All page content sits at `z-index: 1` or above so cards remain fully readable over the gradient.

**JS — progress tracking:**
- Initialise: `document.documentElement.style.setProperty('--gradient-progress', '0%')`
- On each `section-complete` SSE event: calculate `(completedCount / totalSections) * 100` and set `--gradient-progress` on `:root`
- On `done` event: set `--gradient-progress` to `'100%'`
- When `generating === false` (preview mode, docs already exist): set `--gradient-progress` to `'100%'` immediately on page load — gradient fully revealed

**Upload page seed:** `upload.html` already has the Tea Green radial glow (Issue 16.2). This gradient layer is `preview.html` only.

**Test:** assert `id="gradient-layer"` is present in the rendered `preview.html` output.
