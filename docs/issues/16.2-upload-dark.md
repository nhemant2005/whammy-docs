# Issue 16.2 — Upload page dark mode + Tea Green radial glow

**GitHub:** #18
**Label:** ready-for-agent
**Blocked by:** Issue #17 (16.1)

## What to build

Apply the Lumina Docs dark theme to `upload.html` using the design tokens from `theme.css`:

- Page background: `var(--color-base)` (#292F36)
- All card/panel surfaces: `var(--color-surface)` with 1px `var(--color-border)` border
- Primary button (Generate / Use Sample Project): `background: var(--color-primary)`, `color: var(--color-base)`, `border-radius: 8px`
- Drag-drop zone: dark surface with Periwinkle dashed border on hover
- All text in Unageo (inherited from `body` rule); headings `font-weight: 800`, labels/buttons `font-weight: 500`, body `font-weight: 400`
- Error banner styled in dark palette with a red/rose accent visible against the dark background
- Mode selector (Quick / Comprehensive) styled with dark surface and Periwinkle active state

Tea Green radial glow: a fixed `div` at the bottom of the viewport with `pointer-events: none` and `z-index: -1`:
```css
background: radial-gradient(ellipse at bottom, rgba(200, 255, 190, 0.25), transparent 70%);
```
This introduces the brand colour before generation begins, making the upload → generation transition feel continuous.

No raw hex values in template HTML — all colours via CSS custom properties.
